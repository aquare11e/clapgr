# Contributing

## Reporting issues

Open an issue at [github.com/aquare11e/clapgr/issues](https://github.com/aquare11e/clapgr/issues).

## Pull requests

1. Fork the repo
2. Create a feature branch
3. Make your changes
4. Run `shellcheck clapgr` and fix any warnings
5. Open a PR against `main`

## Code style

- Follow existing patterns in the script
- All changes must pass [ShellCheck](https://www.shellcheck.net/) with zero warnings
